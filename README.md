# Dungeon Escape (Pre-alpha)

### 1. Presentación del Proyecto

<u>Descripción General del Proyecto</u>

Dungeon Escape es un videojuego del género de **aventura de texto basada en comandos**. El jugador debe escribir en la terminal la acción que desea hacer, y en base a sus decisiones ocurren distintos eventos. **Su objetivo es escapar de una mazmorra**.

### 3. Características Principales

* El jugador escribe acciones en la terminal para avanzar.
* Si la acción no coincide con las opciones disponibles, se le pregunta de nuevo al jugador.
* Cada opción tiene sus consecuencias.
* Hay varios caminos por elegir.
* Se puede retroceder de camino en determinadas situaciones.
